# Geometry Calculator

This project is a simple text-based Geometry Calculator built using Python classes.  

---

## Features

### Create 2D Shapes
- Circle  
- Rectangle  
- Square  
- Right Triangle  

---

## Menu Options

**1. Create New Shape**  
Prompts the user to choose a shape type and enter its dimensions.

**2. View All Shapes**  
Displays a list of all shapes created so far, including area and perimeter.

**3. Select Shape**  
Shows all details about a specific shape.

**4. Compare Shapes**  
Compares the area and perimeter of any two shapes in the list.

**5. Sort Shapes**  
Sorts all shapes by either:
- Area  
- Perimeter  

**6. Formula Guide**  
Prints the formulas used for each shape.

**7. Quit**  
Exits the program.
