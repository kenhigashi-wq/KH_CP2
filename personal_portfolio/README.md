# Personal Python Portfolio

This project is a graphical Python portfolio that showcases four programming projects I completed during CP2.  
The portfolio a programming resume and allows users to view project descriptions and run each project directly from the interface.

## How to Run
1. Make sure Python is installed
2. Navigate to the `personal_portfolio` folder
3. Run the file:
4. Click on a project to view its description
5. Click **Run Project** to launch the selected program

## Projects Included
- **Simple Morse Code** – Converts text into Morse code
- **Geometry Calculator** – Calculates geometric values like area and perimeter
- **Grade Book** – Stores grades and calculates averages
- **Financial Calculator** – Performs basic financial calculations

## Technologies Used
- Python
- Tkinter
